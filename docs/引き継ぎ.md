## 非交渉ルール（SPEC.cc.md にも記載）
- `window.confirm/prompt` 禁止 → ConfirmDialog/PromptDialog
- main の子（各View root）に **min-width:0**（無いとページごと横に伸びる）
- 折り返しは body の **overflow-wrap: anywhere** 1か所（break-wordでは最小幅が縮まない）
- 色は `--c-*` のみ。ハードコード禁止。虫食いの保存色は `inkColor()` で読み替え
- 学習記録のキーは**問題文**。編集時は `study.moveRecord` で引っ越す（放置すると記録が消える）
- 削除は `removeQuestion/removeGroup` の2経路のみ → ごみ箱を通る。新しい削除口を作らない
- **保存失敗は必ず画面に出す**（pool.saveError と study.saveError の両方）
