# PDF などから問題を作る「変換プロンプト」

選択式問題が載った PDF・画像・テキストを、生成AI（ChatGPT / Claude / Gemini など）に渡して、
**quizmake で読み込める形**に変換してもらうためのプロンプト集。

- **JSON がおすすめ。** Excel を持っていなくても、出てきた文字をそのまま保存すれば読み込める。
- Excel（.xlsx）にしたいときは CSV 版を使う。表計算ソフトに貼って保存する一手間がかかる。
- どちらも **1ファイル＝1グループ**。教科や年度ごとに分けて変換する。

以下の内容は 2026-09-03 に実機で読み込みを確認済み（最小の JSON がそのまま通ることを確認）。

---

## 1. JSON 版（おすすめ）

> **使い方**
> 1. 下の枠の中をすべてコピーして、生成AIに貼り付ける。
> 2. 続けて PDF（または問題のテキスト・写真）を添付して送る。
> 3. 出てきた JSON をコピーし、メモ帳などに貼って **`問題集.json`** という名前で保存する
>    （文字コードは UTF-8。メモ帳なら保存時に選べる）。
> 4. quizmake の「⬆ 読み込む」でそのファイルを選び、「追加する」を押す。

```text
あなたは、試験問題のデータ化を担当する編集者です。
添付した資料に載っている「選択式問題」を、次の仕様の JSON に変換してください。

## 出力する形（この形以外は出力しない）

{
  "app": "quizmake",
  "kind": "backup",
  "version": 2,
  "pool": {
    "groups": [
      { "id": "g1", "name": "ここにグループ名" }
    ],
    "questions": [
      {
        "questionNumber": 1,
        "groupId": "g1",
        "question": "問題文をそのまま",
        "choices": ["選択肢1", "選択肢2", "選択肢3", "選択肢4", "選択肢5"],
        "correctIndexes": [0],
        "explanation": "解説。無ければ空文字",
        "keyPoints": ["覚えておく事項1", "覚えておく事項2"]
      }
    ]
  }
}

## 守ってほしいこと

1. 問題文・選択肢は資料のとおりに書き写す。要約・言い換え・現代語訳をしない。
2. choices は 2〜5個。6個以上ある問題は飛ばし、最後に「飛ばした問題番号」を報告する。
3. correctIndexes は **0から数えた番号**の配列。
   - 1番目が正解 → [0]／3番目が正解 → [2]
   - 「2つ選べ」は [0, 2] のように複数入れる。
4. すべての questions の groupId は、groups の id と**同じ文字**にする。ここが違うと1問も入らない。
5. questionNumber は 1 から続き番号を振る。資料の番号が飛んでいても振り直してよい。
6. explanation（解説）が資料に無ければ、**あなたが1〜3文で書く**。断定できないときは空文字にする。
   推測を事実のように書かない。
7. keyPoints（基本事項）は、その問題で覚えておくべきことを短い文で0〜5個。無ければ空配列。
8. 正解が資料から判断できない問題は**作らない**。最後にまとめて「正解が不明」として報告する。
9. 図・グラフ・写真を見ないと解けない問題は飛ばす。最後に報告する。
10. 文中に丸数字（①②）や「次のうち」などの指示がある場合も、そのまま残す。
11. JSON 以外の文字（説明・```json などの囲み）を**出力の前後に付けない**。
    ただし、最後の「報告」だけは JSON の後ろに、--- で区切って書いてよい。

## グループ名

資料から分かる範囲で「科目_範囲」の形にする（例：日本史_近世、看護_循環器）。
分からなければファイル名をそのまま使う。

## 数式について

数式は $ で挟むと組版される（例：$E = mc^2$、$\frac{1}{2}mv^2$）。
理科・数学で数式が出てくる場合だけ使い、ふつうの文には使わない。

まず資料を読み、問題数を数えてから、上の形の JSON を出力してください。

## 2. CSV 版（Excel にしたいとき）

> **使い方**
> 1. 下の枠をコピーして生成AIに貼り付け、PDF を添付して送る。
> 2. 出てきた表をコピーして Excel に貼り付ける（1行目が見出しになる）。
> 3. Excel の「名前を付けて保存」で **.xlsx** を選ぶ。
>    **ファイル名がそのままグループ名になる**ので、`日本史_近世.xlsx` のように付ける。
> 4. quizmake の「⬆ 読み込む」でそのファイルを選ぶ。

```text
あなたは、試験問題のデータ化を担当する編集者です。
添付した資料に載っている「選択式問題」を、次の12列の表（タブ区切り）に変換してください。

## 列（この順・この見出しのまま。1行目に見出しを置く）

問題番号  問題文  下線キーワード  画像URL  選択肢a  選択肢b  選択肢c  選択肢d  選択肢e  正解  解説  基本事項

## 各列の書き方

- 問題番号：1から続き番号。
- 問題文：資料のとおりに書き写す。要約しない。
- 下線キーワード：**常に空**にする（使わない列）。
- 画像URL：**常に空**にする。
- 選択肢a〜e：2〜5個。足りない列は空のままにする。
- 正解：**a / b / c / d / e** で書く。「2つ選べ」は「a,c」のようにカンマで並べる。
- 解説：資料に無ければ、あなたが1〜3文で書く。断定できないときは空にする。
- 基本事項：複数書くときは「｜」（縦棒）で区切る。無ければ空。

## 守ってほしいこと

1. 区切りは**タブ**。セルの中にタブを入れない。
2. セルの中で改行しない（1問＝1行）。
3. 正解が資料から判断できない問題、図を見ないと解けない問題は作らない。
   最後に「飛ばした問題番号」を表の後ろに報告する。
4. 表以外の文字を、表の前に付けない。

まず資料を読み、問題数を数えてから、表を出力してください。
```

## 3. うまくいかないときの見かた

| 症状 | 原因と直し方 |
| --- | --- |
| 「quizmake で書き出したファイルではないようです」 | JSON の外側（app / kind / version / pool）が欠けている。プロンプトの形をもう一度渡す |
| 読み込めたのに0問 | `groupId` が groups の `id` と違う。両方を `g1` にそろえる |
| 正解の位置がずれる | `correctIndexes` を1から数えている。**0から**に直す |
| 選択肢が1つにつながる | JSON の `choices` が配列になっていない（文字列1つになっている） |
| 文字化けする | 保存時の文字コードが UTF-8 でない。メモ帳なら保存画面で UTF-8 を選ぶ |
| Excel で1列に全部入る | タブ区切りで貼れていない。「データ」→「区切り位置」でタブを指定する |

## 4. 表を入れたいとき（任意）

問題文・解説・基本事項に表を入れられる。JSON では、文中に `[[表1]]` と書き、
その問題に `tables` を足す。

```json
{
  "question": "次の表を見て答えよ。[[表1]]",
  "tables": [
    { "header": true, "rows": [["順位", "都道府県"], ["1", "北海道"], ["2", "岩手県"]] }
  ]
}
```

- 表は1問に9つまで。`[[表1]]` `[[表2]]` … と番号で対応させる。
- 行ごとの列数は必ずそろえる。
- **Excel（.xlsx）には表を入れられない。** 表を使うなら JSON 版を選ぶ。
