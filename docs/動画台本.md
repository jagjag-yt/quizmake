# quizmake 使い方動画 台本

- **撮影**：パソコン（Windows）の画面録画
- **音声**：合成音声（読み上げソフト）
- **本編**：約 2 分 30 秒 ／ **短縮版**：30 秒（X の固定ポスト用）
- ナレーションの文字数は、読み上げ速度を「やや速め」にした場合の目安で組んでいます

---

## 0. 撮影前の準備

台本どおりに撮るには、**先に画面の中身を作っておきます**。撮影中に作ると手が止まり、録り直しが増えます。

### 用意するもの

| 準備 | 内容 |
| --- | --- |
| グループ | 「日本史」を1つ作り、**5問だけ**入れておく（多すぎると一覧が雑然として見えます） |
| Excel ファイル | デスクトップに `日本史.xlsx` を置く。3〜5問で十分。**ファイル名がグループ名になる**ので、見せたい名前にしておきます |
| 虫食い用の文章 | 教科書1文ぶん。例：`鎌倉幕府は源頼朝が開き、執権政治のもとで北条氏が実権を握った。` |
| 学習記録 | 何問か解いて**正答率と学習記録に数字が入った状態**にしておく（0%のグラフは説得力がありません） |
| ブラウザ | ブックマークバーを隠す（Ctrl+Shift+B）。**個人情報が映る拡張機能やタブは閉じる** |
| 表示 | 見た目は「ライト」に固定（設定 → 見た目）。撮影中に端末が暗くなると色が変わるため |

### 録画のしかた（Windows 標準機能）

1. `Win + G` でゲームバーを開く
2. 「キャプチャ」の **● 録画開始**（または `Win + Alt + R`）
3. 止めるときは `Win + Alt + R` をもう一度
4. 保存先は `ビデオ ＞ キャプチャ`

> **ブラウザのウィンドウを最大化して撮ってください。** 途中でウィンドウ幅を変えると、
> 画面の作りが切り替わってしまいます（1280px 未満だと問題作成が切り替え式になります）。

### 撮り方のコツ

- **1カットずつ別ファイルで撮る。** 通しで撮ると、1か所の失敗で全部やり直しになります
- マウスは**ゆっくり動かす**。速いと視聴者が目で追えません
- クリックの前に **0.5秒止める**。どこを押すのかが伝わります
- 入力は**一気に貼り付けず、少し打って見せてから**貼り付けると自然です

## 1. 本編（約 2 分 30 秒）

### カット1 ─ つかみ（0:00〜0:12）

**画面**：完成した演習画面。問題文と選択肢が並び、右に解説が出ている状態を数秒映す。

**ナレーション**
> 教科書やノートを、そのまま問題集にできたら。
> quizmake は、自分で問題を作って解ける学習アプリです。
> 登録もお金もいりません。

**テロップ**：`自分の問題集を、自分で作る` → `quizmake`

> **読み方注記**：「quizmake」は **クイズメイク** と読ませます。読み上げソフトが英語読みしてしまう場合は、原稿に `クイズメイク` とカタカナで入れてください。

---

### カット2 ─ Excel から取り込む（0:12〜0:40）

**画面の動き**
1. 起動直後のグループ一覧を映す
2. 左上の **≡** を押してメニューを開く → **問題作成** を選ぶ
3. **「既存のグループに問題を追加」** ではなく、下の **「⬆ 読み込む」** を押す
4. デスクトップの `日本史.xlsx` を選ぶ
5. 問題が取り込まれ、グループ「日本史」ができる様子を見せる

**ナレーション**
> すでに Excel で問題を作っているなら、そのまま読み込めます。
> ファイルを選ぶだけ。ファイル名が、そのままグループの名前になります。
> 一行が一問。問題文と選択肢、正解、解説を書いておけば、すぐに解ける形になります。

**テロップ**：`Excel をそのまま読み込める`

> **注記**：読み込み後に問題番号が 1 から振り直される様子が映ると分かりやすいです。

---

### カット3 ─ 解いてみる（0:40〜1:10）

**画面の動き**
1. 取り込んだグループの **▶ 演習** を押す
2. 選択肢を1つクリック → **その場で色が変わり、右に解説が出る**
3. 右側の解説と基本事項をゆっくりスクロール
4. **次の問題 →** を押す

**ナレーション**
> 解くのは選ぶだけ。押した瞬間に正解かどうかが分かり、解説がすぐ右に出ます。
> 緑が正解、赤が選んでしまった答えです。
> 選択肢の並びは毎回入れ替わるので、位置で覚えてしまうことがありません。

**テロップ**：`押した瞬間に採点＋解説`

---

### カット4 ─ 虫食いで覚える（1:10〜1:50）

ここが**他のアプリと一番違うところ**です。丁寧に見せます。

**画面の動き**
1. メニュー → **問題作成** → **問題を追加する**
2. ダイアログで **虫食い** を選び、**作成して編集する**
3. 用意した文章を貼り付ける
4. 「源頼朝」を選択して **F1** を押す → 青いマーカーで隠れる
5. 続けて「北条氏」も選択して **F1**
6. 右端の **‹ プレビュー** を押して開き、**演習と同じ見た目**を見せる
7. マーカーをクリックして開く／閉じる様子を見せる

**ナレーション**
> 用語を覚えたいときは、虫食いが使えます。
> 文章を貼り付けて、隠したい言葉を選んで F1 を押すだけ。
> 押すたびに隠れて、もう一度押すと戻ります。
> 解くときはマーカーを押して確認します。
> 覚えるための機能なので、虫食いは採点されません。

**テロップ**：`選んで F1 → 隠れる` / `採点されないので気楽に`

> **補足カット（余裕があれば）**：`[[ ]]` 記法も 5 秒だけ見せると効果的です。
> 文章を打ちながら `[[北条氏]]` と入力すると、閉じ括弧を打った瞬間に括弧が消えて隠れます。
> ナレーション：「打ちながら二重カッコで囲んでも、同じように隠せます。」

---

### カット5 ─ 続けるための仕組み（1:50〜2:15）

**画面の動き**
1. メニュー → **学習記録**
2. 通算正答率・連続学習日数・グループ別の正答率をゆっくり見せる
3. 演習に戻り、条件バーの **条件を変える** を押して **今日の復習** を見せる

**ナレーション**
> 解いた記録は自動で残ります。
> 正解するほど次に出るまでの間隔が延びる仕組みなので、
> 「今日の復習」を選べば、忘れかけたものだけが出てきます。

**テロップ**：`忘れかけた頃に出てくる`

---

### カット6 ─ しめ（2:15〜2:30）

**画面**：スマホ幅の画面（ブラウザの幅を狭めるか、実機で撮る）で演習している様子。

**ナレーション**
> パソコンでもタブレットでもスマートフォンでも、同じ問題集が使えます。
> 記録はこの端末の中だけに保存され、外には送られません。
> 登録は不要。ブラウザで開くだけです。

**テロップ**：`app.quiz-make.com` （大きく、3秒以上）

> **注記**：最後の URL は**最低3秒**映してください。ここが一番の入口です。

## 2. 短縮版（30秒・X の固定ポスト用）

固定ポストは**音を出さずに見る人が大半**です。テロップだけで意味が通るように作ります。

| 秒 | 画面 | テロップ（大きめ） | ナレーション |
| --- | --- | --- | --- |
| 0〜5 | 演習画面で選択肢を押し、解説が出る | `押した瞬間に採点` | 自分で作る問題集、quizmake。 |
| 5〜13 | Excel を読み込み、問題集ができる | `Excel をそのまま読み込める` | Excel の問題をそのまま読み込めます。 |
| 13〜22 | 文章を選んで F1、マーカーが付く | `選んで F1 で虫食い` | 覚えたい言葉は、選んで F1 で隠せます。 |
| 22〜30 | スマホ幅で解く → URL | `登録不要・無料` `app.quiz-make.com` | 登録もお金もいりません。ブラウザで開くだけです。 |

> **1カットあたり最低4秒**は映してください。SNS では切り替えが速すぎると何も伝わりません。

## 3. 合成音声の設定メモ

| 項目 | 設定 |
| --- | --- |
| 速度 | やや速め（標準の 1.1 倍程度）。遅いと最後まで見てもらえません |
| 間 | 文の区切りで 0.3 秒。カットの切れ目で 0.5 秒 |
| 読み方 | `quizmake` → **クイズメイク** ／ `F1` → **エフワン** ／ `Excel` → **エクセル** |
| 音量 | 動画の BGM を入れる場合、BGM は声の 1/4 以下に |

**BGM を入れる場合**は、必ず**商用利用可・クレジット不要**の素材を使ってください。将来この動画に広告が付く可能性があるため、「非営利のみ無料」の素材は避けます。

## 4. 撮影後のチェック

公開前に、次の項目を必ず確認してください。

- [ ] 画面に**個人情報が映っていない**（ブックマーク、他のタブ、通知、メールアドレス）
- [ ] `app.quiz-make.com` の綴りが正しく、3秒以上映っている
- [ ] テロップの誤字（特に「quizmake」の大文字小文字）
- [ ] 音が割れていない／無音の区間が長すぎない
- [ ] スマホで再生して、**テロップの文字が読める大きさ**か

## 5. 公開先と使い分け

| 場所 | 使うもの | 補足 |
| --- | --- | --- |
| X の固定ポスト | 短縮版（30秒） | 一番目に触れるので、ここが本番 |
| ホームページ | 本編（2分30秒） | `quiz-make.com` に埋め込むかリンクする |
| YouTube | 本編 | 限定公開でも可。埋め込み用の置き場として使えます |

> ホームページへの埋め込みは、**動画ができてから**私のほうで対応できます。
> 埋め込みは外部への通信が発生するため、プライバシーポリシーの記載を1行足す必要があります。
> そのときに声をかけてください。
