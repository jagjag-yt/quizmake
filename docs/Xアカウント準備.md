# X アカウントの準備物

凍結が解除された直後です。**まず再凍結を避けることを最優先**にしてください。
せっかく解除されても、初動を誤るともう一度止まります。

---

## 0. 最初の1週間でやってはいけないこと

凍結明けのアカウントは通常より厳しく見られます。次は避けてください。

| 避けること | 理由 |
| --- | --- |
| **1日に何十人もフォローする** | 新規・凍結明けで最も引っかかりやすい行動です。1日 **10人以内**に抑えてください |
| **同じ文面を繰り返し投稿する** | 自動投稿とみなされます。宣伝文は毎回書き換えてください |
| **リンクだけの投稿を続ける** | 投稿の大半にURLが入る状態は危険です。**リンクなしの投稿を混ぜて**ください |
| **解除直後にプロフィールを何度も書き換える** | 1日で確定させ、しばらく触らないでください |
| **知らない人に一斉リプライ・DM** | 最短で再凍結されます |

> **なぜ凍結されたかが分かっているなら、その行動は二度としないでください。**
> 心当たりがない場合でも、上の5つを守れば大きく減らせます。

## 1. プロフィール

### 表示名

```
quizmake（クイズメイク）
```

> カタカナを添えるのは、読み方が伝わらないと口コミで広がらないためです。

### ユーザー名（@ID）

第1候補から順に、空いているものを使ってください。

1. `@quizmake_jp`
2. `@quizmake_app`
3. `@quiz_make_jp`

### 自己紹介（bio）

**A案（機能を先に言う・推奨）**

```
覚えたいことを自分で問題にして、繰り返し解けるWebアプリ。
選択式と虫食いの2種類。Excelの問題集も読み込めます。
登録不要・無料。記録は端末の中だけ。
```

**B案（悩みから入る）**

```
参考書を読んでも覚えられない、を自分で作った問題で解決するWebアプリ。
一問一答も虫食いも作れて、忘れた頃にまた出てきます。
登録不要・無料。
```

> **bio は短めにしてあります。** X の紹介文の上限は160字ですが、日本語を2文字ぶんとして
> 数える場合があるかどうかを、こちらで確認できませんでした。どちらの数え方でも収まる長さに
> してあります。入力欄に貼って余裕があれば、次の1文を足してください。
>
> `使い方や更新はここでお知らせします。`

**推奨は A案** です。フォローするかどうかを決める人は「これは何のアカウントか」を先に知りたいので、機能を先頭に置くほうが伝わります。B案は共感を狙える反面、何のアプリか分かるまでが遅れます。

### 場所・URL・誕生日

| 項目 | 設定 |
| --- | --- |
| 場所 | **空欄のまま**（個人の居住地を推測させない） |
| Webサイト | `https://quiz-make.com` |
| 誕生日 | **公開しない**（設定しても「誰にも表示しない」にする） |

### 画像

すでに用意してあります。

| 種類 | ファイル | サイズ |
| --- | --- | --- |
| アイコン | `brand/icon.png` | 1024×1024 |
| ヘッダー | `brand/header.png` | 1500×500 |

> ヘッダーは**下部と左下がプロフィール画像や文字で隠れます**。設定後、スマホとPCの両方で見て、大事な文字が隠れていないか確認してください。

## 2. 固定ポスト

動画がまだなので、**いまは文章版を固定**し、動画ができたら差し替えます。

### いま固定する版

```
自分で問題集を作って解ける、無料のWebアプリを作りました。

・一問一答も、文章の虫食いも作れる
・Excelの問題集をそのまま読み込める
・間違えた問題は忘れた頃にまた出てくる
・登録不要。スマホでもPCでも
・記録は端末の中だけ

https://app.quiz-make.com
```

### 動画ができたら差し替える版

```
30秒で分かる、自分でつくる問題集アプリ。

作った問題はスマホでもPCでも解けます。
登録不要・無料です。

https://app.quiz-make.com
```
※ 短縮版の動画を添付する

## 3. 最初の投稿（固定ポストのあと・1日1本ずつ）

**同じ日にまとめて投稿しないでください。** 数日に分けます。

### 1本目（リンクなし・作った理由）

```
参考書を読んでも覚えられなくて、自分用に問題集を作るアプリを書きました。
読むだけだと分かった気になるけど、問題にすると分かっていないところが一発で出ます。
```

### 2本目（虫食いの紹介・画像1枚）

```
虫食い問題が作れます。
教科書の文をそのまま貼って、隠したい言葉を選ぶだけ。
「ここ覚えてないな」がすぐ分かります。
```
※ 虫食い編集画面のスクリーンショットを添付

### 3本目（Excel読み込み・画像1枚）

```
すでにExcelで問題を作っている人は、そのまま読み込めます。
ファイルを選ぶだけで、問題集になります。
```
※ 読み込み後の設問一覧のスクリーンショットを添付

### 4本目（リンクあり・改めて案内）

```
無料で使えます。登録もいりません。
ブラウザで開くだけなので、インストールも不要です。

https://app.quiz-make.com
```

## 4. 投稿するときの注意

- **スクリーンショットに個人情報を写さない**（他のタブ、ブックマーク、通知、メールアドレス）
- 画像には**代替テキスト**を付ける（Xの画像編集から設定できます）。見えない人にも伝わります
- **返信には丁寧に、早めに**。凍結明けは「まっとうに使っている」実績を積むのが一番効きます
- 医学生・大学生・資格試験の話題には**自分から絡みに行かず**、まず自分の投稿を積む

## 5. まだやらないこと

| 項目 | 時期 |
| --- | --- |
| 広告を出す | 段階7（利用者200人を超えてから） |
| フォロワーを増やす施策 | まず投稿を10本ほど積んでから |
| 有料機能の告知 | 段階8。いま言うと「結局お金がかかる」と受け取られます |

## 6. 決めてほしいこと

- 表示名・@ID・bio（A案／B案）の確定
- 固定ポストを**いま文章版で置くか、動画を待つか**

私の推奨は「**いま文章版を固定する**」です。アカウントが動いている実績を先に作るほうが、凍結明けには有利だからです。動画ができたら差し替えれば済みます。
