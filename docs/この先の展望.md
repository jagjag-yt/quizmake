# この先の展望（2026-08-25 改訂・広告を最優先に組み直し）

同級生の反応が良かったため、**広告（段階7）を最優先**に順序を入れ替えます。
前の版では「利用者200人超が目安」としていましたが、その条件を外します。

ただし、**広告で得られる金額は当面ほぼゼロ**です。それでも先に着手する価値はあります。
理由と、その前提での組み立てを以下に書きます。

---

## 0. 先に数字の話（ここを外すと計画が狂います）

### 収益の見込み

| 前提 | 数 |
| --- | --- |
| 利用者 | 50人 |
| 1人あたりの月間ページ表示 | 20回（多めに見て） |
| 月間の広告表示 | **1,000回** |
| 日本の表示広告の相場（1,000表示あたり） | おおむね 100〜400円 |
| **月の収益** | **100〜400円** |

**Google AdSense の日本の支払い基準額は 8,000円**です。月300円なら、
振り込まれるまで2年以上かかります。**当面は現金化できないと考えてください。**

8,000円に月単位で届くには、月2万〜8万表示、つまり **1,000〜4,000人規模**の利用が要ります。

### それでも先にやる価値

- **審査に通しておくこと自体が資産**です。人が増えた瞬間に収益化できる状態になります
- 審査には数日〜2週間かかります。人が増えてから始めると、その分だけ遅れます
- 広告枠の置き方（どこに出すと邪魔にならないか）は、**利用者が少ないうちに試すほうが安全**です

> **お金がすぐ欲しい場合、広告は答えになりません。**
> 50人規模で現金化を狙うなら、買切（1,000円）を先に出すほうが現実的です。
> 5人が買えば5,000円で、広告の1年分を超えます。判断は下の「9」に書きます。

## 1. いちばん守るべきもの

いまの最大の資産は**同級生の好感**です。広告はこれを削る方向に働きます。
順序を決める基準は「**評判を減らさずに、広告の受け皿を作る**」ことです。

具体的な原則を3つ置きます。

1. **演習中の画面には出さない。** 解いている最中に広告が入ると集中が切れます。
   ここを削ると、アプリそのものが使われなくなります
2. **最初はホームページだけ。** アプリ内は、様子を見てから1枠だけ
3. **導入時に一言添える。** 「無料で続けるために広告を入れました」と先に言うだけで、
   受け取られ方が変わります

## 2. 新しい順序

### Phase 0：実測（いま・30分）

**すべての前提がここです。** Cloudflare Web Analytics で次を見てください。

- この1週間の**訪問者数**（配った人数のうち、実際に何人が開いたか）
- **ページ別**の表示回数（`/` `/guide` `app.quiz-make.com`）
- **再訪**の有無

この数字が分かると、広告の見込み額も、枠を置く場所も具体的に決まります。
**数字を教えてください。** それに合わせて以下の見積もりを直します。

### Phase 1：広告の受け皿を作る（1〜2日・私の作業）

審査を受けるのは **quiz-make.com（ホームページ）** です。
`app.quiz-make.com` は中身が利用者の端末の中にしかないので、
審査する側から見ると「内容が無いページ」に見え、落ちやすい構造です。

| やること | 中身 |
| --- | --- |
| プライバシーポリシー改定 | 第5項に広告事業者への送信、第8項の「予定」から広告を外す、オプトアウトの案内（Google の広告設定へのリンク） |
| 利用規約 | 広告掲載の条項を足す |
| `ads.txt` | 両ドメインの直下に置く（承認後に発行される行を書く） |
| 内容の追加 | **審査対策**として読み物を2〜3本（例：「虫食いで覚えるコツ」「過去問をExcelにする手順」「間隔をあけて復習する理由」）。いまのトップ＋使い方だけでは薄いと判断される可能性があります |

### Phase 2：AdSense に申請（あなたの作業・審査待ち1〜14日）

- Google アカウントで申請し、サイト所有の確認タグを貼る（私がHTMLに入れます）
- **審査中は待つだけ**です。落ちた場合は理由が示されるので、内容を足して再申請します

### Phase 3：ホームページに1枠（承認後・半日）

- トップの記事下、または使い方ページの本文末に**1枠だけ**
- 枠の高さを先に確保して、読んでいる途中で文章が動かないようにします
- 1週間、収益とページ表示を見ます

### Phase 4：アプリに1枠（Phase 3 の1週間後・半日）

出す場所は次の2つだけを候補にします。**演習画面には出しません。**

- **結果画面の下**（区切りがついた場所で、いちばん自然）
- 設問一覧の末尾

あわせて確認すること。

- 画面がガタつかないこと（枠の高さを先に取る）
- **オフラインでも壊れないこと**（電波が無くても解けるのがこのアプリの利点です）
- 不適切なカテゴリの遮断設定（学習用途に合わない広告を止める）

### Phase 5：続けるか決める（1か月後）

- 収益が月300円未満で、かつ「広告が邪魔」という声が1つでも出たら、**アプリ内は外す**
- ホームページの枠は残す（利用者の邪魔にならないため）

## 3. 段階8（課金）の組み替え

広告を先に出すなら、課金の中身は**「広告を消す」**に組み替えるのが噛み合います。

| 前の案 | 新しい案 |
| --- | --- |
| 月300円／買切1000円（同期などの機能） | **買切1,000円で広告を消す**（機能はすべて無料のまま） |

理由は3つです。

- 広告が入るほど「消す」価値が上がります。**広告と課金が同じ方向を向きます**
- 機能を有料にすると、無料の人の体験が悪くなります。広告非表示なら誰も損をしません
- 「預ける・取り戻す」は無料のまま（決定済み）を守れます

課金を始めるときに必要な実務は前の版と同じです。**特定商取引法に基づく表記**（氏名・住所・
連絡先・価格など）の掲載義務、決済（Stripe・手数料3.6%前後）、返金の方針、規約改定。
個人の住所を出す点が引っかかりやすいので、始めると決めた時点で確認してください。

## 6. 私からの推奨（順番に）

1. **Phase 0 の数字をください。** 実際の訪問者数が分かると、この計画は具体化できます
2. **Phase 1〜2 を先に進めます。** 審査は待ち時間が長いので、早く出すほど得です
3. **アプリ内の広告は、ホームページで1週間試してから。** 好感を減らさない順序です
4. **現金がすぐ要るなら、買切（広告非表示）を先に**。50人規模ではそちらのほうが早いです
