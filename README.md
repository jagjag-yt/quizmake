# QBオンライン風クイズアプリ

医師国家試験の演習サイト「QBオンライン」のUIを参考にした自作クイズWebアプリ。
問題を左カラム、解答結果・解説を右カラムに表示する2カラムレイアウトで、
選択肢クリックによる正誤判定・リトライ・問題送りが動作します。

デザインハンドオフ（`design_handoff_quiz_app/`）の Hi-fi プロトタイプを
**React + Vite + Tailwind CSS v4** で再現したものです。

## セットアップ

```bash
npm install       # 依存関係のインストール
npm run dev       # 開発サーバー（http://localhost:5173）
npm run build     # 本番ビルド（dist/ へ出力）
npm run preview   # ビルド結果のプレビュー
```

## 状態管理

| state | 説明 |
| --- | --- |
| `currentIndex` | 現在の問題インデックス（0始まり） |
| `selectedIndex` | クリックした選択肢のインデックス（未選択は `null`） |
| `answered` | 回答済みかどうか |

- `select(idx)` … 未回答時のみ選択を確定し `answered = true`
- `retry()` … 同じ問題で選択・回答状態をリセット（回答済み時のみ活性）
- `goPrev()` / `goNext()` … 問題を移動し選択・回答状態をリセット（先頭/末尾で非活性）

### 選択肢のランダム表示

選択肢は表示順をランダム化しています（正解の位置も毎回変わります）。

- 並びは **問題を移動したとき・リトライしたとき・Excel を読み込んだとき** に再シャッフルされます。
- 回答を選んで結果を表示している間は並びが固定されます（正誤ハイライトがずれないように）。
- 実装は [`src/utils/shuffle.js`](src/utils/shuffle.js)。表示順の配列（`order`）を state に持ち、
  それに合わせて選択肢と `correctIndex` を写した「表示用の問題」を組み立てる方式です。
  元データ（`src/data/questions.js` / Excel）の並びや正解定義は変更しません。

## データモデル（Excel連携を見据えた拡張しやすい構造）

`src/data/questions.js` の各レコードは、そのまま外部データ（Excel等）の
1行スキーマとして再利用できます。

```js
{
  questionNumber: number,
  segments: [{ text: string, u: boolean }], // u:true の箇所に下線（キーワード強調）
  choices: string[],       // 最大5件（a〜e、順序＝配列順・可変長）
  correctIndex: number,    // choices 内の正解インデックス
  explanation: string,     // 解説文
  keyPoints: string[],     // 基本事項の箇条書き
}
```

外部データ読み込みへ拡張する際は、この `QUESTIONS` 配列を
パース済みレコードで差し替えるだけで対応できます。

## Excel（.xlsx）読み込み

ヘッダーの **「📄 Excelを読み込む」** ボタンから `.xlsx` / `.xls` を選ぶと、
その内容で出題データが差し替わります（先頭の問題に戻ります）。
サンプルテンプレートを [`public/sample_questions.xlsx`](public/sample_questions.xlsx) に同梱しています。

### シートの書き方

- **1行目 = ヘッダー、2行目以降 = 1問につき1行**。
- 読み込むのは**先頭シート**です。
- 列の順番は自由。ヘッダー名で対応付けます。

| 列（ヘッダー） | 必須 | 内容 | 記入例 |
| --- | :---: | --- | --- |
| `問題番号` | 任意 | 表示する問題番号。空欄なら上から自動採番 | `1` |
| `問題文` | **必須** | 問題文（プレーンテキスト） | `急性心筋梗塞の…どれか。` |
| `下線キーワード` | 任意 | 問題文中で**下線強調**したい語句。複数は「、」「,」または改行で区切る | `超急性期、心電図変化` |
| `選択肢a`〜`選択肢e` | a,bは必須 | 選択肢。**空欄の列は自動でスキップ**（2〜5択に対応） | `ST上昇` |
| `正解` | **必須** | 正解の選択肢。`a`〜`e` / `1`〜`5` / 選択肢の文字列そのもの、いずれでも可 | `a` |
| `解説` | 任意 | 解説文（文中の読点「、」はそのまま保持されます） | `…最初に出現する。` |
| `基本事項` | 任意 | 箇条書き。項目の区切りは**改行（セル内 Alt+Enter）** または「｜」「\|」 | 下記参照 |

### 記入のポイント

- **下線キーワード**は短い語句の列挙なので「、」区切りでOK。問題文中の**一致する箇所すべて**が下線になります。
- **基本事項**は文（読点を含む）なので、区切りは**改行のみ**です。「、」では区切られません。
  - セル内改行は Excel で **Alt+Enter**。改行が使いにくい場合は「｜」（全角）でも区切れます。
  - 例（1セル内）:

    ```
    ST上昇 → 異常Q波 → 陰転化したT波、という経時的変化を覚える
    ST上昇は障害心筋に一致した誘導に出現する
    異常Q波は不可逆的な心筋壊死を反映する
    ```
- **正解**は `a` でも `1` でも、選択肢テキストそのものでも指定できます。
- ヘッダー名は別名も許容します（例：`問題文`→`question`、`正解`→`answer`、`選択肢a`→`選択肢1` など）。
- 変換できない行があると、**何行目のどの項目が問題か**をボタン下にメッセージ表示します（読み込みは中断）。

> パース処理は [`src/utils/parseExcel.js`](src/utils/parseExcel.js)、
> UIは [`src/components/ExcelLoader.jsx`](src/components/ExcelLoader.jsx) にあります。
> xlsx ライブラリはボタン押下時に**動的import**され、初期表示のバンドルには含まれません。
