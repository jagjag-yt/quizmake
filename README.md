# QBオンライン風クイズアプリ

医師国家試験の演習サイト「QBオンライン」のUIを参考にした自作クイズWebアプリ。
問題を左カラム、解答結果・解説を右カラムに表示する2カラムレイアウトで、
選択肢クリックによる正誤判定・リトライ・問題送りが動作します。

デザインハンドオフ（`design_handoff_quiz_app/`）の Hi-fi プロトタイプを
**React + Vite + Tailwind CSS v4** で再現し、学習アプリとして機能拡張したものです。

学習記録はすべて**この端末のブラウザ内（localStorage）にのみ保存**され、外部には送信されません。

## 主な機能

| 機能 | 概要 |
| --- | --- |
| 問題演習 | 選択肢クリックで即時に正誤判定＋解説表示。リトライ・前後移動 |
| 選択肢のランダム表示 | 表示順を毎回シャッフル（正解位置も追従） |
| 複数選択（2つ選べ） | 国試形式の複数正解に対応。必要数を選んで「解答する」 |
| 画像つき問題 | 心電図・X線などの画像を表示（URLはスキームを検証） |
| Excel 読み込み | 自作の問題集に差し替え（[書き方](#excelxlsx-の書き方)） |
| ブックマーク | ★で保存し、ブックマークだけの復習セッション |
| 要復習モード | 直近で間違えた問題だけを出題 |
| 間隔反復（SRS） | 正解するほど復習間隔が延びる。「今日の復習」で対象を出題 |
| 科目・タグ絞り込み | 分野別の集中演習／出題数の指定 |
| 番号ジャンプ | 「問題〇」に番号を入力して任意の問題へ移動 |
| 自分メモ | 問題ごとにメモを保存し、次回表示 |
| 本番モード | 制限時間つき・解説を伏せて連続で解き、終了後に一括採点 |
| 結果画面 | 正答率・所要時間・問題ごとの結果／間違えた問題の復習導線 |
| 学習ダッシュボード | 日別学習量・正答率推移・科目別成績・定着度・連続学習日数 |
| キーボード操作 | `a`〜`e` / `Enter` / `←→` / `R` / `S` / `?` |
| データ入出力 | 学習記録を JSON で書き出し／読み込み（バックアップ・端末移行） |

## セットアップ

```bash
npm install       # 依存関係のインストール
npm run dev       # 開発サーバー（http://localhost:5173）
npm run build     # 本番ビルド（dist/ へ出力）
npm run preview   # ビルド結果のプレビュー
```

サンプル問題集の再生成:

```bash
node scripts/generate-sample-xlsx.mjs
```

## 使い方

### 出題条件（ツールバー）

- **モード**：全問題／★ブックマーク／要復習／今日の復習
- **科目・タグ**：分野を絞って演習（インターリービングにも活用）
- **出題数**：5〜50問をランダム抽出
- **本番モード**：制限時間つき。解説を伏せ、終了後に一括採点

条件を変えると新しいセッションが始まります。「この条件で開始」で出題を引き直せます。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `a`〜`e` / `1`〜`5` | 選択肢を選ぶ |
| `Enter` | 解答する（2つ選べ）／次の問題へ |
| `→` / `←` | 次の問題 / 前の問題 |
| `R` | リトライ |
| `S` | ブックマークの登録・解除（`b` は選択肢bと重なるため） |
| `?` | ショートカット一覧 |

### 間隔反復（SRS）の仕組み

Leitner ボックス方式です。正解すると箱が1つ上がり、次の出題までの間隔が延びます。
間違えると箱0に戻り、その日のうちに再出題されます。

| 箱 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 次回まで | 当日 | 1日 | 3日 | 7日 | 16日 | 35日 |

「今日の復習」モードで、復習日が来た問題だけを出題できます。

### 学習データの保存とバックアップ

- 保存先は **localStorage のみ**（キー: `quizmake.data.v2`）。サーバー送信はありません。
- ブラウザのデータを消すと学習記録も消えます。**「書き出し」で定期的にバックアップ**してください。
- 別の端末やブラウザへは、書き出した JSON を「読み込み」で移行できます（統合／置き換えを選択）。
- 旧バージョンのデータ（`quizmake.bookmarks.v1` / `quizmake.stats.v1`）は初回起動時に自動移行します。

## データモデル

`src/data/questions.js` の各レコードは、そのまま外部データ（Excel等）の1行スキーマとして再利用できます。

```js
{
  questionNumber: number,
  segments: [{ text: string, u: boolean }], // u:true の箇所に下線（キーワード強調）
  choices: string[],        // 最大5件（a〜e、順序＝配列順・可変長）
  correctIndexes: number[], // 正解のインデックス（複数指定で「2つ選べ」）
  explanation: string,      // 解説文
  keyPoints: string[],      // 基本事項の箇条書き
  subject: string,          // 科目（絞り込み・集計）
  tags: string[],           // タグ（絞り込み）
  imageUrl: string | null,  // 画像（検証済みURLのみ）
}
```

## Excel（.xlsx）の書き方

ヘッダーの **「📄 Excelを読み込む」** から `.xlsx` / `.xls` を選ぶと、その内容で出題データが差し替わります。
記入済みのテンプレートを [`public/sample_questions.xlsx`](public/sample_questions.xlsx) に同梱しています。

- **1行目 = ヘッダー、2行目以降 = 1問につき1行**
- 読み込むのは**先頭シート**。列の順番は自由（ヘッダー名で対応付け）

| 列 | 必須 | 内容 | 例 |
| --- | :---: | --- | --- |
| `問題番号` | 任意 | 空欄なら自動採番 | `1` |
| `科目` | 任意 | 絞り込み・科目別成績に使用 | `循環器` |
| `タグ` | 任意 | 「、」区切りで複数可 | `心電図、虚血性心疾患` |
| `問題文` | **必須** | 問題文 | `急性心筋梗塞の…どれか。` |
| `下線キーワード` | 任意 | 下線強調する語句。**「、」/改行**区切り | `超急性期、心電図変化` |
| `画像URL` | 任意 | `http(s)` または画像の data URL | `https://example.com/ecg.png` |
| `選択肢a`〜`選択肢e` | a,b必須 | **空欄列は自動スキップ**（2〜5択） | `ST上昇` |
| `正解` | **必須** | `a`〜`e` / `1`〜`5` / 選択肢文字列 | `a` |
| `解説` | 任意 | 解説文（読点はそのまま保持） | `…最初に出現する。` |
| `基本事項` | 任意 | 箇条書き。**改行(Alt+Enter)** or「｜」区切り | 下記 |

### 記入のポイント

- **「2つ選べ」形式**は、`正解` を「、」区切りで複数指定します（例：`a、c`）。
  アプリ側では必要数を選ぶまで「解答する」が押せません。
- **下線キーワード**は短い語句なので「、」区切りでOK。問題文中の一致箇所すべてに下線が付きます。
- **基本事項**は文（読点を含む）なので**改行区切りのみ**。1セル内で Alt+Enter、または「｜」で区切ります。
  ```
  ST上昇 → 異常Q波 → 陰転化したT波、という経時的変化を覚える
  ST上昇は障害心筋に一致した誘導に出現する
  異常Q波は不可逆的な心筋壊死を反映する
  ```
- **正解**は `a`・`1`・選択肢テキストのどれでも指定可。
- ヘッダー名は別名も許容します（`問題文`→`question`、`正解`→`answer`、`科目`→`subject` など）。
- 変換できない行があると、**何行目のどの項目か**を表示して中断します。
- 学習記録は**問題文をキー**に保存されるため、Excel を差し替えても同じ問題文なら記録は引き継がれます。

## セキュリティ方針

ユーザーが用意したファイルをブラウザ内で解析するアプリのため、次の対策を実装しています。

- **プロトタイプ汚染対策**：JSON の読み込み時に `__proto__` / `constructor` / `prototype` キーを除去し、
  学習記録は `Object.create(null)` ベースのマップで保持（`src/utils/safe.js`）。
- **画像URLの検証**：`http(s)` と画像の data URL のみ許可。`javascript:` 等は破棄。
  値は `<img src>` にのみ渡し、HTML として挿入しません（`dangerouslySetInnerHTML` は不使用）。
- **入力サイズの上限**：Excel 15MB・5000問、インポートJSON 8MB、記録2万件、メモ2000文字。
- **取り込みデータの正規化**：型・範囲・日付形式を検証し、想定外の値は既定値に落とします。
- **保存失敗の可視化**：localStorage の容量超過などはエラーとして画面に表示します。
- **依存の最小化**：グラフは自作SVG。外部CDNスクリプトは使用しません。
- **`xlsx` は公式配布の修正版を固定**（npm 版 0.18.5 の既知脆弱性を回避）。詳細は
  [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) を参照。

脆弱性の確認:

```bash
npm audit
```
