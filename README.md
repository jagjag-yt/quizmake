# quizmake

自作の問題集で演習できる学習Webアプリ。
問題を左カラム、解答結果・解説を右カラムに表示する2カラムレイアウトで、
選択肢クリックによる正誤判定・リトライ・問題送りが動作します。

Excel で作った問題集を読み込めるほか、ブックマーク・間隔反復・学習記録に対応しています。
**React + Vite + Tailwind CSS v4** で実装しています。

学習記録はすべて**この端末のブラウザ内（localStorage）にのみ保存**され、外部には送信されません。

## 主な機能

| 機能 | 概要 |
| --- | --- |
| 問題演習 | 選択肢クリックで即時に正誤判定＋解説表示。リトライ・前後移動 |
| 選択肢のランダム表示 | 表示順を毎回シャッフル（正解位置も追従） |
| 複数選択（2つ選べ） | 国試形式の複数正解に対応。必要数を選んで「解答する」 |
| 画像つき問題 | 心電図・X線などの画像を表示（URLはスキームを検証） |
| Excel 読み込み | 自作の問題集に差し替え（[書き方](#excelxlsx-の書き方)） |
| ブックマーク | ★で保存し、ブックマークだけの復習セッション |
| 要復習モード | 直近で間違えた問題だけを出題 |
| 間隔反復（SRS） | 正解するほど復習間隔が延びる。「今日の復習」で対象を出題 |
| グループ絞り込み | グループ別の集中演習／出題数の指定 |
| 番号ジャンプ | 「問題〇」に番号を入力して任意の問題へ移動（番号はグループごとに 1,2,3…） |
| 自分メモ | 問題ごとにメモを保存し、次回表示 |
| 本番モード | 制限時間つき・解説を伏せて連続で解き、終了後に一括採点 |
| 結果画面 | 正答率・所要時間・問題ごとの結果／間違えた問題の復習導線 |
| 学習ダッシュボード | 日別学習量・正答率推移・グループ別成績・定着度・連続学習日数 |
| キーボード操作 | `a`〜`e` / `Enter` / `←→` / `R` / `S` / `?` |
| データ入出力 | 学習記録を JSON で書き出し／読み込み（バックアップ・端末移行） |
| アプリとして起動 | ホーム画面に追加して全画面で起動。**オフラインでも演習可能**（PWA） |
| グループ | 問題を「グループ」にまとめて管理。統合・分割ができる（旧「科目」の置き換え） |
| 設問一覧 | グループを一覧 → 選ぶとその設問一覧。検索・種別・状況で絞り込み。選んだ問題の複製・移動・削除 |
| 問題作成 | アプリ内で問題を作成・編集し、演習画面と同じプレビューで確認。Excelへ書き出し |
| 虫食いモード | 文章の一部をマーカーで隠し、タップで開閉して覚える。**採点はしない** |
| 設定 | 規約・プライバシー・お問い合わせへのリンク／全データの削除（通知は準備中） |

## はじめかた（起動方法）

### 初回だけ：準備する

コマンドプロンプト（または PowerShell）を開き、プロジェクトのフォルダへ移動してから実行します。

```bash
cd C:\Users\Owner\Documents\quizmake
```

```bash
npm install
```

> 必要なファイルを取り寄せる作業です。1〜2分かかります。2回目以降は不要です。
> `npm` が見つからない場合は [Node.js](https://nodejs.org/) をインストールしてください。

### 毎回：起動する

```bash
npm run dev
```

表示された **http://localhost:5173** をブラウザで開きます。

### 終了する

コマンドプロンプトの画面で **Ctrl + C** を押します。

> **公開版を使う場合**
> 起動作業もパソコンも不要です。ブラウザで開くだけで使えます。
>
> | | URL | 配信元 |
> | --- | --- | --- |
> | アプリ | <https://app.quiz-make.com> | Cloudflare Workers（`npm run build` → `dist`） |
> | ホームページ | <https://quiz-make.com> | Cloudflare Workers（`site/public` をそのまま配信） |

## アプリとして使う（PC・iPad）

公開した URL を開いて「ホーム画面（デスクトップ）に追加」すると、**ブラウザのアドレスバーが消え、
アプリとして全画面で起動**します。追加後は**オフラインでも演習できます**（電波の届かない場所でも可）。

| 端末 | 手順 |
| --- | --- |
| **iPad / iPhone**（Safari） | 共有ボタン <kbd>⬆</kbd> →「**ホーム画面に追加**」→「追加」 |
| **PC**（Chrome / Edge） | アドレスバー右端の <kbd>⊕</kbd> インストールアイコン →「インストール」 |
| **Android**（Chrome） | メニュー <kbd>⋮</kbd> →「**アプリをインストール**」 |

- ストアへの登録は不要で、**費用もかかりません**。URL を共有すれば誰でも同じ手順で使えます。
- オフラインで使えるのは**一度でも開いたことがある端末**です（初回はネット接続が必要）。
- 内容を更新したときは、オンラインで開けば自動的に最新版に入れ替わります。

> **iPad・iPhone をお使いの方へ**
> Safari には、**7日間サイトを開かないと保存データを削除する**仕様があります。
> 「ホーム画面に追加」しておくと削除されにくくなりますが、
> 大切な記録は「**書き出し**」で定期的にバックアップしてください。

```

│           ├───────────────────────────────────────────────┤
│ 設問一覧   │  全問題 · 地理 / 5問で出題中 / 条件を変える        │ ← 出題条件（1行要約）
│ 演習 ●     ├────────────────────┬──────────────────────────┤
│ 問題作成   │ 問題 1  グループ名 ☆ │                          │
│ 学習記録   │                     │   正解と解説              │
│ ───────  │ 問題文（下線は重要語） │   基本事項                │
│ アカウント │                     │   自分メモ                │
│ 設定      │  a  選択肢1          │                          │
│           │  b  選択肢2          │ ← 選択肢を選ぶと出てきます │
```

- 画面の切り替えは左の **≡ メニュー（ドロワー）** から行います。ヘッダーには ≡ とロゴだけが並びます。
- **正答率はヘッダーに出しません。**「学習記録」の「通算正答率」だけで確認します
  （リセットも学習記録の画面にあります）。
- ヘッダーの **「⋯」メニューと「?」ボタンは廃止**しました。ショートカット一覧は**設定**にあります。
- **ロゴを押すと、いつでも設問一覧のグループ一覧（起動直後と同じ場所）に戻ります。**
- メニューは**どの画面幅でも本文の上に重なって開きます**。背景が薄く暗くなり、パネルが左からすべり込みます。
  本文が右へずれることはありません。項目を選ぶ・暗い部分を押す・`Esc` のどれでも閉じます。

## 使ってみる（最初の3分）

1. **選択肢をクリック** → その場で正誤が色分けされ、右側に解説が出ます
   （緑＝正解／赤＝あなたが選んだ不正解）
2. **右側の解説と基本事項を読む** → 下の「自分メモ」に覚え方を書いておくと次回も表示されます
3. **あとで解き直したい問題は右上の ☆ ブックマーク** を押します
4. **「次の問題 →」** で進みます（キーボードの `→` でも同じ）
5. 最後の問題まで進むと **「結果を見る」** に変わり、採点結果が出ます
6. 左の **≡ メニュー →「学習記録」** で、正答率の推移や苦手なグループが確認できます

> **選択肢の並びは毎回シャッフルされます。**「答えは3番目」と位置で覚えてしまうのを防ぐためです。
> 「2つ選べ」の問題では、必要な数だけ選んでから「解答する」を押します。

## おすすめの学習の流れ

| タイミング | やること | 使うモード |
| --- | --- | --- |
| 毎日のはじめ | 前に間違えた問題の復習から入る | **今日の復習** |
| そのあと | 新しい問題を進める（グループを絞ると集中しやすい） | **全問題** ＋ グループ |
| 週末 | 苦手をまとめて潰す | **要復習** / **★ブックマーク** |
| 試験前 | 時間を計って本番の練習 | **本番モード**（制限時間つき） |

「今日の復習」は**間隔反復**の仕組みで、正解するほど次の出題が先に延びます（当日→1日後→3日後→1週間後…）。
忘れかけたタイミングで出てくるので、少ない回数で記憶が定着します。

> 💾 **学習記録はこのブラウザ内だけに保存されます。**
> 定期的に **問題作成** 画面の左下「書き出す」でバックアップを取ってください（別の端末へも移せます）。

## 使い方

### 出題条件（ツールバー）

- **モード**：全問題／★ブックマーク／要復習／今日の復習
- **グループ**：グループを絞って演習（インターリービングにも活用）
- **出題数**：5〜50問をランダム抽出
- **本番モード**：制限時間つき。解説を伏せ、終了後に一括採点

条件バーは既定で1行の要約（例：`全問題 · 地理 / 5問で出題中 / 条件を変える`）にたたまれています。
「条件を変える」を押すと展開します。**条件を変えた時点で新しいセッションが始まります**
（かつての「この条件で開始」ボタンは、押し忘れの原因になるため廃止しました）。

> **1回の演習は1つのグループだけを対象にします。**グループの絞り込みに「すべて」はありません。
> 問題番号がグループごとの連番のため、混ぜると番号が重複して「問題〇」で指定できなくなるからです。

### キーボードショートカット

| キー | 動作 |
| --- | --- |
| `a`〜`e` / `1`〜`5` | 選択肢を選ぶ |
| `Enter` | 解答する（2つ選べ）／次の問題へ |
| `→` / `←` | 次の問題 / 前の問題 |
| `R` | リトライ |
| `S` | ブックマークの登録・解除（`b` は選択肢bと重なるため） |
| `?` | ショートカット一覧（演習中のみ。一覧は設定にも常設） |

### 問題タイプ（選択式 / 虫食い）

問題には2つのタイプがあり、作成時に選びます（**あとから変更はできません**）。

| | 選択式 | 虫食い |
| --- | --- | --- |
| 答え方 | a〜eから選ぶ | 文章のマーカーをタップして開閉 |
| 採点 | される | **されない** |
| 正答率・要復習・今日の復習・定着度 | 反映される | **含まれない** |
| 本番モード | 使える | 使えない |
| Excel | 読み書きできる | **アプリ内のみ** |
| ブックマーク・メモ・グループ | 使える | 使える |

**虫食いの作り方**
1. 問題作成タブの「＋ 問題を追加」→ グループとタイプ（虫食い）を選ぶ
2. 文章を入力する（見出しは任意）
3. 隠す箇所を指定する。方法は2つあり、どちらを使っても同じです
   - **選んでボタン**：隠したい部分を選択して「■ 隠す」（ショートカット **Ctrl+F1**、`Ctrl`/`⌘`+`H` でも可）
   - **`[[ ]]` で囲む**：`植物は葉の[[葉緑体]]で` のように入力すると、**閉じ括弧を打った時点で括弧が消え**、
     その語が隠す箇所になります。書きながら指定できるので、文章を打ち込む場合はこちらが速いです
4. 文字色（6色）は装飾用で、隠す指定とは別に使えます
5. 右のプレビューで、演習画面と同じ見た目を確認できます

**虫食いの解き方**
- マーカーをクリック／タップすると中身が見え、もう一度押すと隠れます（キーボードの Enter / Space でも操作できます）
- 上部の「すべて表示 / すべて隠す」、下部の「↻ 隠し直す」で一括操作できます
- 1つの文章が1問です（文章の中にマーカーがいくつあっても1問）

### グループ

問題はかならず1つの**グループ**に属します（旧「科目」の置き換え）。

- **設問一覧**タブは、まずグループの一覧を表示します。グループを選ぶとその設問一覧に入ります。
- **Excel は1ファイル＝1グループ**として取り込まれます（グループ名はファイル名）。
  ただし**問題作成でグループを開いている最中に読み込んだときは、そのグループの末尾に追加**されます
  （新しいグループは作られず、番号は既存の続きから振られます）。
- **問題作成**では、先にグループを作る／選ぶことから始めます（入口がグループを決める画面になっています）。
  左カラムでは、**グループを増やす「＋ 新規」**と、**問題を増やす「＋ 問題を追加」**を線で分けています。
- **統合**：グループ一覧で2つ以上を選び「統合する」で1つにまとめます。
- **分割**：設問一覧で問題を選び「別グループへ分割」で新しいグループへ切り出します。
- 学習記録は**グループ別**に集計されます。

**並び順**：グループ一覧の右上で **名前順 / 更新順** を選び、隣のボタンで**昇順・降順**を切り替えます。

| 並び順 | 昇順 | 降順 |
| --- | --- | --- |
| 名前順 | ↑ あ→ん | ↓ ん→あ |
| 更新順 | ↑ 古い順 | ↓ 新しい順 |

選んだ並び順は次回も引き継がれます。「更新」は、そのグループの**問題を追加・編集・削除・移動したとき**と
**グループ名を変えたとき**に記録されます（学習しただけでは変わりません）。

### 設定

左の ≡ メニューの一番下から開きます。

- **通知**（準備中）：「今日の復習」がたまったときに知らせる機能。端末に通知を届けるにはアカウントが必要なため、
  アカウント機能と一緒に提供します。
- **規約とプライバシー**：[利用規約](https://quiz-make.com/terms.html) /
  [プライバシーポリシー](https://quiz-make.com/privacy.html) / [お問い合わせ](mailto:support@quiz-make.com)
- **キーボードショートカット**：一覧を常設しています（キーボードのあるパソコン向け）。
- **データ**：作成した問題と学習記録をすべて消して最初の状態に戻します（確認ダイアログを必ず経由します）。
  消す前に「書き出す」で控えを取ってください。

### 演習画面プレビューの出しかた（問題作成）

- **画面幅 1280px 以上**：左カラム・編集欄・プレビューの3列を同時に表示します。
- **1280px 未満（iPad は縦・横とも）**：上部の **[編集｜プレビュー]** で切り替えます。
  問題一覧は **「☰ 問題一覧（N）」** から開きます。

iPad の横向き（1194px など）で3列に並べると、プレビューが 279px しか取れず選択肢が折り返してしまうためです。
**縦向きと横向きで操作が変わらない**ことを優先しています。

### スマートフォンでの制限（意図的なもの）

画面幅が **600px 以下のとき、問題作成は編集画面を開かず案内画面を表示します**。
この幅では選択肢の入力欄が数文字分しか取れず、まともに入力できないためです。故障ではありません。

- **演習・設問一覧・学習記録・設定はスマホでも使えます。**作った問題はそのまま解けます。
- どうしても必要なときは、案内画面の「それでもこの端末で作成する」から編集画面へ進めます。

### 間隔反復（SRS）の仕組み

Leitner ボックス方式です。正解すると箱が1つ上がり、次の出題までの間隔が延びます。
間違えると箱0に戻り、その日のうちに再出題されます。

| 箱 | 0 | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- | --- |
| 次回まで | 当日 | 1日 | 3日 | 7日 | 16日 | 35日 |

「今日の復習」モードで、復習日が来た問題だけを出題できます。

### 学習データの保存とバックアップ

- 保存先は **localStorage のみ**。サーバー送信はありません。

  | キー | 内容 |
  | --- | --- |
  | `quizmake.pool.v2` | グループと問題（作成した問題そのもの） |
  | `quizmake.data.v2` | 学習記録（正誤・SRS・ブックマーク・メモ） |
  | `quizmake.groupSort.v1` | グループ一覧の並び順 |
  | `quizmake.listState.v1` | 設問一覧の絞り込み（sessionStorage。タブを閉じると消えます） |

- ブラウザのデータを消すと学習記録も消えます。**「書き出し」で定期的にバックアップ**してください。
- 別の端末やブラウザへは、書き出した JSON を「読み込み」で移行できます（統合／置き換えを選択）。
- 旧バージョンのデータ（`quizmake.bookmarks.v1` / `quizmake.stats.v1`）は初回起動時に自動移行します。

## データモデル

`src/data/questions.js` の各レコードは、そのまま外部データ（Excel等）の1行スキーマとして再利用できます。

```js
// 選択式
{
  id: string,               // 問題のID
  type: 'choice',           // 問題タイプ（作成後は変更できません）
  questionNumber: number,   // グループ内の連番（常に 1,2,3…）
  segments: [{ text: string, u: boolean }], // u:true の箇所に下線（キーワード強調）
  choices: string[],        // 最大5件（a〜e、順序＝配列順・可変長）
  correctIndexes: number[], // 正解のインデックス（複数指定で「2つ選べ」）
  explanation: string,      // 解説文
  keyPoints: string[],      // 基本事項の箇条書き
  groupId: string,          // 所属グループのID（旧「科目」）
  imageUrl: string | null,  // 画像（検証済みURLのみ）
}

// 虫食い（Excelには書き出されません）
{
  id: string,
  type: 'cloze',
  questionNumber: number,
  groupId: string,
  title: string,            // 見出し（任意）
  paras: [[{ text: string, hide: boolean, color: string }]], // 段落の配列
}
```

## Excel（.xlsx）の書き方

**問題作成** 画面の左カラム（1問も無いときは入口の画面）にある **「読み込む」** から `.xlsx` / `.xls` を選ぶと、
その内容がグループとして取り込まれます。
記入済みのテンプレートを [`public/sample_questions.xlsx`](public/sample_questions.xlsx) に同梱しています。

- **1行目 = ヘッダー、2行目以降 = 1問につき1行**
- 読み込むのは**先頭シート**。列の順番は自由（ヘッダー名で対応付け）
- **1ファイル＝1グループ**として取り込まれます（グループ名はファイル名）。グループの列はありません
  - **例外**：問題作成でグループを開いている最中に読み込むと、そのグループの**末尾**に追加され、
    番号は既存の続き（例：1,2 のところへ5問読み込むと 3〜7）になります

| 列 | 必須 | 内容 | 例 |
| --- | :---: | --- | --- |
| `問題番号` | 任意 | 読み込み時は使わず、グループ内で1から振り直します | `1` |
| `問題文` | **必須** | 問題文 | `急性心筋梗塞の…どれか。` |
| `下線キーワード` | 任意 | 下線強調する語句。**「、」/改行**区切り | `超急性期、心電図変化` |
| `画像URL` | 任意 | `http(s)` または画像の data URL | `https://example.com/ecg.png` |
| `選択肢a`〜`選択肢e` | a,b必須 | **空欄列は自動スキップ**（2〜5択） | `ST上昇` |
| `正解` | **必須** | `a`〜`e` / `1`〜`5` / 選択肢文字列 | `a` |
| `解説` | 任意 | 解説文（読点はそのまま保持） | `…最初に出現する。` |
| `基本事項` | 任意 | 箇条書き。**改行(Alt+Enter)** or「｜」区切り | 下記 |

### 記入のポイント

- **「2つ選べ」形式**は、`正解` を「、」区切りで複数指定します（例：`a、c`）。
  アプリ側では必要数を選ぶまで「解答する」が押せません。
- **下線キーワード**は短い語句なので「、」区切りでOK。問題文中の一致箇所すべてに下線が付きます。
  - 同じ語句が複数あり、**特定の1か所だけ**に下線を引きたい場合は `語句@2`（2番目の出現）のように位置を指定できます。
    アプリの「Excelに書き出す」では、必要なときだけこの形式が自動で付きます（手入力では通常不要です）。
- **基本事項**は文（読点を含む）なので**改行区切りのみ**。1セル内で Alt+Enter、または「｜」で区切ります。
  ```
  ST上昇 → 異常Q波 → 陰転化したT波、という経時的変化を覚える
  ST上昇は障害心筋に一致した誘導に出現する
  異常Q波は不可逆的な心筋壊死を反映する
  ```
- **正解**は `a`・`1`・選択肢テキストのどれでも指定可。
- ヘッダー名は別名も許容します（`問題文`→`question`、`正解`→`answer` など）。
- 変換できない行があると、**何行目のどの項目か**を表示して中断します。
- 学習記録は**問題文をキー**に保存されるため、Excel を差し替えても同じ問題文なら記録は引き継がれます。

## セキュリティ方針

ユーザーが用意したファイルをブラウザ内で解析するアプリのため、次の対策を実装しています。

- **プロトタイプ汚染対策**：JSON の読み込み時に `__proto__` / `constructor` / `prototype` キーを除去し、
  学習記録は `Object.create(null)` ベースのマップで保持（`src/utils/safe.js`）。
- **画像URLの検証**：`http(s)` と画像の data URL のみ許可。`javascript:` 等は破棄。
  値は `<img src>` にのみ渡し、HTML として挿入しません（`dangerouslySetInnerHTML` は不使用）。
- **入力サイズの上限**：Excel 15MB・5000問、インポートJSON 8MB、記録2万件、メモ2000文字。
- **取り込みデータの正規化**：型・範囲・日付形式を検証し、想定外の値は既定値に落とします。
- **保存失敗の可視化**：localStorage の容量超過などはエラーとして画面に表示します。
- **依存の最小化**：グラフは自作SVG。外部CDNスクリプトは使用しません。
- **`xlsx` は公式配布の修正版を固定**（npm 版 0.18.5 の既知脆弱性を回避）。詳細は
  [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) を参照。

脆弱性の確認:

```bash
npm audit
```
