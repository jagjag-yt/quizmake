プライバシーポリシー

制定日：2026年8月16日／最終改定日：2026年8月26日

要点。 quizmake は、入力した問題も、正答率などの学習記録も、お使いの端末の中に保存します。 運営者のサーバーへ送るのは、アカウントを作って「預ける」を押したときだけです。 アカウントを作らずに使うこともでき、その場合、運営者がお預かりする情報はありません。

1. 端末の中に保存される情報

本サービスは、ブラウザの保存領域（ローカルストレージ）に次の情報を保存します。 これらが外部へ送信されるのは、利用者が「預ける」を押したときだけです （第6項）。押さないかぎり、端末の外には出ません。

保存する場所 内容 目的
quizmake.pool.v2 作成した問題、グループ 次に開いたときに問題を表示するため
quizmake.data.v2 正答率、ブックマーク、メモ、復習の予定 間違えた問題の復習に使うため
quizmake.listState.v1 設問一覧の絞り込み条件 画面を移動しても条件を保つため（タブを閉じると消えます）
quizmake.sync.v1 ログインの鍵（トークン）とメールアドレス アカウントを使うとき、毎回ログインしなくてよくするため（未使用なら保存されません）
quizmake.drawer メニューを開いているかどうか 次回も同じ状態で表示するため

これらは、アプリの「設定 → すべてのデータを削除」、 またはブラウザの「サイトデータの削除」でいつでも消すことができます。

2. Cookie について

運営者自身は Cookie を使用していません。第3項のアクセス解析も、Cookie やブラウザの保存領域を使わずに行われます。

ただし、広告を掲載している場合、広告配信事業者が Cookie を使用することがあります （第5項）。これは広告の表示と効果測定のためのもので、運営者がその内容を受け取ることはありません。

3. アクセス解析

どれくらいの方に使われているかを把握するため、Cloudflare, Inc. が提供する Cloudflare Web Analytics を利用しています（2026年8月21日から）。

  • Cookie や端末への保存を行わず、個人を識別・追跡しません。
  • 記録されるのは、閲覧されたページ、参照元（どのサイトから来たか）、おおまかな地域、 ブラウザや端末の種類、表示にかかった時間などです。
  • 作成した問題の内容や学習記録は、解析の対象になりません。 これらは第1項のとおり、お使いの端末の中だけに保存されます。
  • Cloudflare Web Analytics について
  • Cloudflare プライバシーポリシー

4. 自動的に記録される情報

本サービスは Cloudflare, Inc. のサーバーから配信しています。 ウェブサイトの一般的な仕組みとして、接続時に IP アドレス、ブラウザの種類、 アクセス日時などが同社のログに記録されます。 これは不正アクセスの防止と安定した配信のために使われるもので、 運営者が個人を識別する目的で利用することはありません。

5. 外部サービスへの送信

本サービスは、文字を読みやすく表示するために Google LLC が提供する Google Fonts を読み込んでいます。この際、利用者の IP アドレスが同社へ送信されます。

また、アカウントを使う場合に限り、ログイン用の6桁の数字をメールで送るため、 Resend（Plus Five Five, Inc.）へ利用者のメールアドレスを送信します。 アカウントを使わない場合、この送信は発生しません。

広告の配信：本サイトおよびアプリでは、無料で提供を続けるための費用として、 Google LLC などの広告配信事業者による広告を掲載することがあります。広告の配信にあたり、 同社が Cookie や広告識別子を用いて、利用者の閲覧履歴に基づく広告を表示する場合があります。 広告の配信のために、利用者が作成した問題や学習記録が送信されることはありません。

パーソナライズ広告（閲覧履歴に基づく広告）は、 Google の広告設定からいつでも無効にできます。無効にしても本サービスは同じように利用できます。

  • Google プライバシーポリシー
  • Resend プライバシーポリシー
  • 広告 – ポリシーと規約（Google）

6. アカウント（預ける・取り戻す）

アカウントは任意です。作らなくても、本サービスのすべての機能を使えます。 アカウントを作り、アプリの「アカウント」画面で「預ける」を押したときにだけ、 次の情報を運営者のサーバー（Cloudflare D1）でお預かりします。

お預かりするもの 目的 保持する期間
メールアドレス ログインと、預けたものの持ち主の確認 退会するまで
預けた問題・グループ・学習記録 端末が壊れたときなどに取り戻すため 1日1件・新しい7日分（古いものは自動で消えます）
端末の名前（例：Windows の Chrome）と利用日時 ログイン中の端末を利用者自身が確認できるようにするため ログアウトするまで（最大3台）

ログイン用の6桁の数字と、端末に配る鍵（トークン）は、そのままの形では保存せず、 ハッシュ（復元できない形）に変換して保存します。パスワードはお預かりしません。

アプリの「アカウント → 退会」を押すと、 預けたもの・メールアドレス・端末の記録をすべて削除します。元に戻すことはできません。 端末の中にある問題と学習記録は、退会しても消えません。

7. 第三者への提供

運営者は、利用者の情報を第三者に提供しません。 アカウントを使わない場合、運営者が保持している情報はありません。 アカウントを使う場合にお預かりするものは第6項のとおりで、 法令に基づく開示の求めがある場合を除き、外部には提供しません。 アクセス解析や配信のために Cloudflare, Inc. が取り扱う情報については、第3項・第4項をご覧ください。

8. 今後の予定

今後、次の機能を追加する予定があります。いずれも、導入する際には本ポリシーを改定し、 本サイト上でお知らせします。お知らせなく取り扱いを変更することはありません。

  • 複数の端末での自動同期：現在は、利用者が押したときだけ預け・取り戻す形です。 自動で双方向に同期する機能を追加する場合は、取り扱いをあらためてお知らせします。
  • 有料プラン：広告を消すための買い切りを検討しています。導入する際は、 決済事業者へ渡る情報とあわせてお知らせします。

9. 開示・訂正・削除のご希望

アカウントを使っていない場合、運営者は利用者の情報を保持していないため、開示できる情報はありません。 端末内のデータは、利用者ご自身でいつでも削除できます（第1項参照）。

アカウントを使っている場合、お預かりしている内容はアプリの「アカウント」画面で いつでも確認でき、「退会」ですべて削除できます（第6項参照）。 操作できない事情があるときは、第10項のお問い合わせ先までご連絡ください。

10. お問い合わせ

本ポリシーに関するご質問は、 support@quiz-make.com までご連絡ください。
